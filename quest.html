Conexión con el Rol

¿Por qué este proyecto importa aquí?

Canvas Quest no es un proyecto genérico de portafolio — demuestra directamente las competencias que la Coordinación de Comunidades Virtuales en el Tec requiere.

🎓

Diseño, administración y producción de comunidades virtuales sobre Canvas LMS

Este proyecto implicó conectarme a la API de Canvas LMS para leer, estructurar y visualizar datos de cursos en tiempo real. Diseñé la arquitectura de la comunidad virtual, programé los recursos educativos dentro de la plataforma y construí un sistema de indicadores de visitas e interacción — las mismas responsabilidades descritas en la vacante de Coordinador de Comunidades Virtuales del Tec.

Diseño y desarrollo de comunidades virtuales

Diseñé la arquitectura completa de la comunidad sobre Canvas: estructura de módulos, flujos de navegación, recursos educativos y experiencia del participante.

Programación y ensamble de cursos virtuales

Configuré módulos, actividades y recursos dentro de Canvas LMS con HTML personalizado, y construí el frontend que visualiza su estructura en tiempo real.

Generación de indicadores de interacción

Generé métricas derivadas de la API de Canvas: tasa de entrega, avance por módulo, tiempo de última actividad y score de engagement por alumno.

Extracción y validación de datos para reportes

Consumí múltiples endpoints de Canvas API (enrollments, submissions, modules, grades), validé y transformé los datos para generar reportes y listas comparativas.

HTML, programación y plataformas educativas

Proyecto construido íntegramente con HTML, CSS y JavaScript vanilla, integrando directamente la API REST de Canvas LMS sin dependencia de frameworks externos.

Innovación en recursos educativos digitales

Propuse e implementé una capa de innovación sobre Canvas: la metáfora RPG como sistema de visualización que hace los datos de la comunidad más intuitivos y accionables.

El Proyecto

Resumen

Comunidad Virtual Gamificada sobre Canvas LMS

Diseño UI/UX · Desarrollo Frontend · Canvas LMS API · Inteligencia Artificial

Diseñé e implementé una capa de visualización gamificada sobre Canvas LMS que transforma los datos crudos de calificaciones y módulos en una experiencia tipo RPG. El docente puede ver en segundos quién avanza, quién necesita atención y cómo va el grupo por módulo, sin exportar datos ni abrir hojas de cálculo.

El sistema incluye modo demo con datos ficticios para exploración sin credenciales, y modo live que se conecta directamente a la API de Canvas para mostrar datos reales del curso en tiempo real.

Herramientas y Metodologías

Canvas LMS API JavaScript HTML / CSS Gemini AI Figma Design Thinking User Research Gamification UX WCAG 2.1 Usability Testing
🎯

Problema Central

Los docentes tardaban demasiado analizando datos de Canvas para identificar alumnos en riesgo.

💡

Solución

Dashboard gamificado conectado a Canvas API que convierte datos fríos en visualizaciones intuitivas.

🚀

Impacto

Tiempo de diagnóstico grupal reducido de ~8 minutos a menos de 90 segundos con docentes reales.

Funcionalidad

Las Tres Vistas

Cada vista cubre un objetivo específico dentro del ciclo de gestión y animación de una comunidad virtual de aprendizaje.

🏆

Tabla de Héroes

Leaderboard gamificado donde cada participante tiene nivel, barra de XP y badges desbloqueados según su desempeño en Canvas.

  • Niveles: Aprendiz → Leyenda
  • Puntuación derivada de datos reales de Canvas
  • Ficha individual con estadísticas detalladas
  • Badges automáticos por logros académicos
🗺️

Mapa de la Aventura

Los módulos del curso se visualizan como islas en un mapa interactivo, mostrando el progreso grupal y el estado de cada zona de aprendizaje.

  • Módulos del curso mapeados visualmente
  • Avance porcentual grupal por módulo
  • Módulos bloqueados indicados con candado
  • Estado individual y colectivo unificado
🤖

Guía IA

Chat integrado con Gemini que recibe el contexto completo del curso y genera análisis y recomendaciones pedagógicas en lenguaje natural.

  • Análisis de desempeño grupal por IA
  • Identificación de participantes en riesgo
  • Sugerencias pedagógicas contextualizadas
  • Reportes en lenguaje natural para el coordinador
Metodología

Proceso de Diseño y Desarrollo

Del problema real al producto funcional, con metodología centrada en el usuario docente y en las capacidades reales de Canvas LMS.

01

Investigación de Usuarios

Entrevistas con docentes para identificar friction en el análisis de calificaciones en Canvas. Creé personas y mapas de empatía representando perfiles reales de profesores universitarios.

02

Definición del Problema

Necesidad de identificar alumnos en riesgo en menos de 2 minutos. Definí KPIs de diseño: tiempo de análisis, tasa de adopción y satisfacción percibida con la plataforma virtual.

03

Arquitectura de la Comunidad

Diseñé la estructura de información de la comunidad virtual, flujos de navegación y mapas de conversación para el componente IA, garantizando coherencia con la plataforma Canvas.

04

Diseño de UI y Sistema de Diseño

Sistema de diseño con paleta oscura, tipografía display para los elementos épicos y componentes reutilizables. Todos los estados de la interfaz documentados en Figma.

05

Implementación y Canvas API

Integración con Canvas LMS API consumiendo endpoints de inscripciones, calificaciones, módulos y entregas. Modo demo para facilitar adopción sin necesidad de token.

06

Pruebas e Iteración

Pruebas de usabilidad con 6 docentes universitarios. El tiempo promedio de diagnóstico bajó de 8 min a menos de 90 segundos. Los indicadores fueron ajustados con base en feedback cualitativo.

Diseño

Principios Aplicados

Cada decisión de diseño está vinculada a un objetivo educativo concreto, no a la estética por sí sola.

Gamificación con Propósito Pedagógico

Los niveles y XP reflejan datos reales de Canvas. Cada badge corresponde a un logro académico verificable — la gamificación es una capa de interpretación de la comunidad, no de distracción.

Indicadores Visuales de Interacción

El color señala el estado de cada participante: el coordinador entiende el estado de la comunidad en una sola mirada, sin necesidad de leer tablas numéricas.

Modo Demo para Adopción sin Fricción

Los coordinadores pueden explorar la herramienta sin comprometer su token de Canvas. Reduce la resistencia al cambio y facilita la presentación a equipos académicos.

IA como Apoyo al Coordinador

El Guía IA ahorra tiempo de análisis inicial y propone hipótesis sobre el estado de la comunidad que el coordinador valida con su conocimiento del grupo. Es un co-piloto, no un sustituto.

Mobile-First para Contexto Real

Diseñado primero para tablet, luego escalado a desktop. Los coordinadores frecuentemente revisan el estado de la comunidad desde dispositivos móviles entre sesiones.

Accesibilidad WCAG 2.1

Contraste AA, navegación por teclado y etiquetas aria para garantizar que la comunidad virtual sea accesible para todos los miembros de la institución.
