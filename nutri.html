Resumen del Proyecto

Dashboard de Reportes — Nutrición para objetivos fitness

Análisis de Datos Educativos · Tecnología Moodle

Diseñé y desarrollé un dashboard de reportes completo para el curso de Moodle "Nutrición para objetivos fitness". La herramienta centraliza los datos de alumnos, calificaciones y progreso en una interfaz visual clara, y permite exportar la información en múltiples formatos Excel para facilitar el análisis por parte de coordinadores y docentes.

Stack tecnológico:

React Vite Recharts SheetJS (xlsx) Lucide React Moodle REST API JavaScript ES6+ HTML/CSS

4 Vistas Principales

Cada vista responde a una necesidad específica del coordinador académico.

Vista Descripción
Vista general KPIs globales, actividad semanal, distribución de calificaciones y objetivos fitness del curso.
Por módulo Tasa de finalización y promedios desglosados por cada uno de los 6 módulos del curso.
Alumnos Tabla filtrable y ordenable con todos los inscritos, incluyendo su progreso individual.
Exportar Descarga de reportes Excel en 5 formatos distintos, listos para análisis o presentación.

Funcionalidades Clave

Visualización de Datos

Gráficas interactivas con Recharts para actividad semanal, distribución de calificaciones y avance por módulo. Los datos se leen de forma inmediata y sin configuración adicional.

Tabla de Alumnos

Componente filtrable y ordenable que muestra todos los inscritos con su progreso. Permite buscar por nombre, ordenar por calificación y detectar rápidamente a alumnos rezagados.

Exportación a Excel

5 tipos de reportes .xlsx generados con SheetJS: reporte completo, resumen del curso, lista de alumnos, calificaciones detalladas y reporte por módulo — cada uno con sus hojas específicas.

KPIs Globales

Indicadores clave visibles desde la vista general: total de inscritos, tasa de finalización, promedio del curso y participación. Diseñados para una lectura instantánea por parte del coordinador.

Análisis por Módulo

Vista dedicada a los 6 módulos del curso con métricas individuales de finalización, promedio de calificación y tiempo promedio de dedicación por parte de los alumnos.

Integración con Moodle

Arquitectura preparada para conectarse a la API REST de Moodle. El archivo mockData.js puede reemplazarse con llamadas reales a funciones como gradereport_user_get_grade_items.

Integración con Moodle REST API

El dashboard está diseñado para conectarse a cualquier instancia de Moodle. Solo se necesita un token de acceso para reemplazar los datos simulados con información real del curso.

Funciones REST utilizadas:

  • core_enrol_get_enrolled_users — alumnos inscritos
  • gradereport_user_get_grade_items — calificaciones por alumno
  • core_completion_get_course_completion_status — estado de finalización

Arquitectura del Proyecto

Componentes Modulares

StatCard.jsx para KPIs, StudentsTable.jsx para la tabla filtrable y ExportPanel.jsx para el panel de descargas. Cada componente es reutilizable e independiente.

Capa de Datos Desacoplada

Todos los datos simulados viven en src/data/mockData.js. Para conectar a datos reales solo se modifica ese archivo, sin tocar la lógica de los componentes ni las vistas.

Exportación Centralizada

La lógica de SheetJS está encapsulada en src/utils/exportExcel.js. Genera 5 formatos distintos con múltiples hojas por reporte, manteniendo el código limpio y escalable.
